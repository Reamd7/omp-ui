# Oh My Pi + OpenChamber

本项目为 [Oh My Pi](https://opencode.ai) Agent 补充一个好看、易用的可视化界面，整体设计参考自 [OpenChamber](https://github.com/openchamber/openchamber)——一个为 OpenCode 提供跨端（桌面 / 浏览器 / 移动端）富交互界面的开源项目。

## 目标

- 为 Oh My Pi Agent 提供一个界面精美、体验流畅的前端
- 复用 OpenChamber 成熟的交互模式与视觉语言（分支对话、Diff 查看、Plan/Build 模式、工具调用 UI 等）
- 保持轻量、易于二次开发与定制
